PixelView 1.2.2 · Windows x64 免安装看图器

开始使用
解压后双击 PixelView.exe。程序内含所需运行时，无需另装 .NET 或 ImageMagick。
可以把图片拖到窗口、拖到 PixelView.exe，或按 Ctrl+O 打开。

设为系统默认看图器
在 PixelView 中点“设置 → 默认打开方式”，勾选需要的格式，再点“设为默认打开方式”。
在打开的 Windows 默认应用页面中，将所选扩展名的默认应用改成 PixelView。
如果 Windows 显示默认应用总览，在其中搜索并打开 PixelView。
系统确认后，当前账户双击对应图片即会启动 PixelView，重启后仍然有效。
首次使用该功能会在 %LOCALAPPDATA%\Programs\PixelView 保留程序副本，
以后移动或删除解压目录也能继续使用已设置的默认打开方式。
需要换回其他应用时，在 Windows 的“默认应用”中为相应扩展名重新选择。

像素画
滚轮以鼠标指向的画布位置为中心缩放，左键拖动只平移图片。
“像素模式（最近邻）”默认开启。向上、向下缩放均使用最近邻采样。
开启“整数倍率放大”可在 100%、200%、300% 等整倍倍率间切换。
按 1 可回到原始像素大小。按 0 可居中并适应画布。
低于 100% 时，一部分原图像素会被跳过，颜色边缘依然保持硬朗。

窗口
滚轮不会改变窗口位置和大小。点右下角“固定窗口”或按 Ctrl+L，可锁定窗口位置和大小。
右击画布或点“设置”，可以调整窗口尺寸、置顶、切换无边框和全屏、隐藏工具栏或状态栏，
也可更换画布背景。在“透明背景”中可选择棋盘格、白色、黑色、灰色或跟随画布，切换立即保存；仅改变预览底色，原图透明通道保持不变。窗口位置、大小和显示选项会在正常退出时保存。
横向和纵向均可继续缩小，最小保留 1 个物理像素的画布，外部仍有系统边框和标题栏。
空间不足时工具栏和状态栏自动收起，放大后恢复。仍可右击画布打开设置，或使用快捷键。
无边框模式下，解锁窗口后可拖动工具栏空白处来移动窗口。
F11 切换全屏，Esc 退出全屏。Ctrl+T 显示或隐藏工具栏。

翻图和播放
顶部“固定视图”或 Ctrl+K：翻图时保留当前倍率和拖动位置，开关状态会在退出后保存。
关闭固定视图后，新图片按画布适应显示。按 0 可随时重新居中适应，按 1 回到实际像素。
鼠标靠近画布左右边缘时显示翻图箭头；停留约 1.8 秒后淡出，离开边缘或拖图时隐藏。
这个开关与右下角固定窗口分别控制图片视图和窗口位置、大小。
← / →     按文件名顺序浏览同一目录的图片
Ctrl+V    粘贴剪贴板中的图片、本地图片路径或文件
+ / -     以画布中心缩放
Space     暂停或继续播放动图
PgUp/Dn   切换帧或页

从旧版升级
解压后运行新版 PixelView.exe。
已经设置系统默认打开方式的用户，可在新版设置里再点一次“设为默认打开方式”，
以更新默认关联使用的程序副本。首次复制前请关闭旧版窗口。

格式
实测样本包括 PNG、JPEG、BMP、GIF、WebP、APNG、TIFF、ICO、SVG、HEIC、AVIF、
JPEG XL、JPEG 2000、PSD、DDS、TGA、OpenEXR、QOI 和 Nikon NEF。
“打开图片”的“所有文件”过滤器可尝试读取其他扩展名。具体兼容性取决于编码和文件变体。
SVG 会栅格化显示，分层文件按合成图预览。PDF、PostScript 和视频不在本版查看范围内。
单帧上限约 1.1 亿像素。超过内存预算的 APNG 会尝试显示静态预览。

第三方组件
解码主要由 Magick.NET / ImageMagick 提供，部分格式通过 Windows 图像组件读取。
